# Free Firearm Sound Library — sources d'armes Forgia

- Créateurs/enregistreurs : Ben Jaszczak, Brian Nelson, Kevin Heras et Matthew Nanney.
- Source : https://opengameart.org/content/the-free-firearm-sound-library
- Licence : Creative Commons Zero 1.0 — aucun droit réservé.

Les quatre FLAC sont des extraits lossless des fichiers préparés du pack :

| Fichier Forgia | Enregistrement source |
|---|---|
| `pepin_ruger.flac` | Ruger Mark III — `R_30P.wav` |
| `bourrasque_m45.flac` | Carl Gustav M45 — `G_20P.wav` |
| `lenoir_mosin.flac` | Mosin Nagant — `M_21P.wav` |
| `boucherie_mossberg.flac` | Mossberg — `N_26P.wav` |

Les fichiers runtime sont filtrés, atténués et exportés par
`tools/audio/generate_forgia_da.py`. L'attribution n'est pas obligatoire mais
reste conservée dans le dépôt et les métadonnées OGG.
