# Raw Sources

> Stockage brut des articles, papers, benchmarks ingérés par `/ia-veille` ou manuellement.
> L'IA lit mais ne modifie JAMAIS ce dossier (sauf ajout de nouveaux fichiers).
> Les insights extraits vont dans MemPalace (drawers/KG) et docs/log.md.

## Convention de nommage

`YYYY-MM-DD_slug.md` — ex: `2026-04-09_karpathy-llm-wiki.md`

## Workflow

1. Nouvelle source (article, gist, paper) → sauver ici en markdown
2. Ingestion → extraire insights dans MemPalace + log.md
3. Re-ingestion possible plus tard avec de meilleures questions
