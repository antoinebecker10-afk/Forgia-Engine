## 6. Benchmark industrie 2024-2026

### 6.1 Workspaces Rust grande échelle

| Projet | Crates / modules | Stratégie |
|---|---|---|
| Bevy core | ~30 | DAG strict par feature (render/ecs/pbr/ui) |
| Servo | ~200 | Fine-grained, layout DAG complexe |
| Unreal Engine 5 | ~100 modules + plugins | Plugin DAG explicite, modules ~10kLOC |
| Zed editor | ~80 | DAG modéré |
| **Forgia V2** | **258** | **Fine-grained extrême** |

**Source primaire** : pas de littérature publique 2024-2026 prônant > 200 crates pour un moteur jeu solo-dev. **Ni source disqualifiante**. La discipline est l'arbitre.

**Risques objectifs** (Rust Book ch.14, Tweag 2025-07) : (a) re-link cascade si crate racine touché, (b) prelude en cascade annule bénéfice incrémental, (c) overhead `cargo metadata`.

**Bénéfices objectifs** : (a) modification isolée recompile uniquement crate touché + directs, (b) lisibilité concept-by-concept cohérente CLAUDE.md §11, (c) parallélisme `cargo build` maximisé.

**Verdict** : 258 crates **défendable si** (1) DAG strict acyclique (✅ validé §2), (2) crates feuilles ≥ 100 LOC utiles à terme (220 SCAFFOLD à surveiller), (3) prelude minimaliste (à vérifier).

### 6.2 Larian 4-layer model — source primaire confirmée

[docs.larian.game/Generic_behaviour](https://docs.larian.game/Generic_behaviour) **en ligne 2026-05-19**, citation primaire :

> *"the framework is in code, the definitions are in text files (data), the behaviours are in Script, the exceptions are in Story."*

**Transposition Forgia** :
- **framework** = `crates/forgia-core`, `forgia-game`, gros crates Rust (terrain, rpg, fps, combat)
- **definition** = `config/genomes/*.toml`, `config/*.json`
- **behaviour** = scripts Luau via `bevy_mod_scripting` (Cargo.toml stack présent, scaffolds `forgia-script-*` 5 crates non wired)
- **exception** = quêtes RPG / events story-driven (`forgia-quests` SCAFFOLD)

CLAUDE.md §3 étape 0 mapping confirmé valide.
